🔖 SpudCall
  1. iPhone Safari: Tap Copy bookmarklet above. Bookmark any page (Share → Add Bookmark). Open Bookmarks → Edit → tap that bookmark → paste into the URL field (replace the whole URL) → Done. Rename it “SpudCall”.
  2. Android Chrome: Tap Copy bookmarklet. Bookmark any page (⋮ → ☆). Edit the bookmark → paste into the URL → Save. Rename it “SpudCall”.
  3. Desktop: Drag the purple “SpudCall” link to your bookmarks bar.

To place a call: tap CALL TEST / CALL FRONT DESK above (it opens the dialer in a new tab), then tap the SpudCall bookmark. The caller takes over the dialer, dials, and speaks — silently.

How it works & limits
• The dialer runs in your real browser (real phone, real IP) — that's why it doesn't hit the bot-check that killed the GitHub runner.
• The order audio is the pre-generated Chatty Porch voice, read from Firebase. When you change the order, fresh audio is generated into Firebase before you call.
• The caller listens for the staff (sound level only, no transcription), says goodbye, and hangs up. You hear nothing — no speakerphone.
• $0: FreeCallMe free credit / PopTox free. No card, no paid service.
• If FreeCallMe shows a 6-digit code screen, the code is relayed via Firebase (E.T. reads Gmail and writes it there) — just wait on that screen.
